## Description

Game Content Creator Toolkit is an MIT-licensed Tauri desktop application for
game-content creators. It retrieves user-selected official public media from
supported game storefront APIs and saves it locally for use in review and
editing workflows. The project uses automated GitHub Actions builds and does
not include telemetry, advertising, user accounts, DRM bypass, or private
account credential capture.
