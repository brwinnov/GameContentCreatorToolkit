# Security Policy

## Supported Versions

Security fixes target the latest published release and the current `main`
branch. Older prerelease builds might not receive fixes.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/brwinnov/GameContentCreatorToolkit/security/advisories/new)
with reproduction steps, affected versions, impact, and any suggested fix.

Do not include credentials, private media, personal file paths, or other
sensitive data unless strictly necessary. Redact examples wherever possible.
The maintainer will acknowledge actionable reports, investigate them, and
coordinate disclosure after a fix or mitigation is available.

The project's current source-security findings and remediation backlog are in
[`docs/SECURITYAUDIT.md`](docs/SECURITYAUDIT.md).
