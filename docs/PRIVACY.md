# Privacy Policy

Game Content Creator Toolkit does not include telemetry, analytics,
advertising, user accounts, or a project-operated remote service. It does not
transfer information to other networked systems unless specifically requested
by the user or the person installing or operating it.

## Network Requests

The application makes the following user-requested network requests:

- Steam searches and trailer downloads send the supplied Steam App ID to
  Steam's public store API and retrieve the selected public media from Steam's
  content delivery network. Valve's privacy policy applies to these requests.
- The Windows ffmpeg installation action retrieves release metadata, checksums,
  and the selected archive from GitHub and BtbN's FFmpeg-Builds repository.
  GitHub's privacy statement applies to these requests.

The application does not send trailer history, selected output paths, local
file names, or ffmpeg settings to the project maintainers.

## Local Data

Trailer history and ffmpeg settings are stored locally under the application's
user-local data directory. Downloaded media is written only to a location the
user selects. Normal application updates and uninstallation may preserve this
data; deleting the application data directory removes it.
